## 简体中文

GrokBot Cloudstandby是一个专为 Grok Bot 准备的保活技能。你可以让它在指定时间内保持云电脑活跃，方便远程连接和运行任务。

### 它能做什么

- **按需保活**：为远程连接或长任务设置保活时间，短至几小时，长至 24 小时。
- **陪任务运行**：登记已有进程，或按照你的指示启动指定命令；任务结束后告诉你结果。
- **到时自动结束**：设置明确的截止时间，到期后停止保活；不会擅自结束你的任务。
- **安静地工作**：多个登记共用一个保活看守，尽量减少重复对话和输出。

### 关于消耗

在一次实际使用中，保活 **5小时约消耗账号额度的 2%～3%**。这是单个账号的参考数据，实际消耗会因套餐、上下文和运行情况而不同。

### 01 · 安装

打开 Grok Bot，复制下面这段话发给它：

```text
请帮我安装这个技能：https://github.com/aritosi/GrokBot-Cloudstandby
请完整安装 skills/grokbot-cloudstandby 目录，包括 SKILL.md 和 scripts。安装完成后先不要启动，告诉我结果。
```

等待 Bot 告诉你安装完成，就可以开始使用。

### 02 · 开始保活

复制下面这句话，按需要修改时间，然后发给 Bot：

```text
请帮我保活云电脑 24 小时。
```

也可以告诉它具体的任务和截止时间：

```text
请帮我保活云电脑，到今天晚上 11 点。
```

有明确需要启动的命令或正在运行的进程时，把命令或进程信息一并告诉 Bot。时间不明确时，它会先和你确认。

### 03 · 停止保活

```text
请停止保活。
```

## 日本語

GrokBot Cloudstandbyは、Grok Bot のクラウドコンピューターを指定した時間内、アクティブに保つためのスキルです。リモート接続やタスクの実行に役立ちます。

### できること

- **必要な時間だけ保活**：リモート接続や長時間タスクに合わせて、数時間から24時間まで指定できます。
- **タスクを見守る**：実行中のプロセスを登録したり、指定したコマンドを起動したりできます。終了後は結果をお知らせします。
- **期限になったら終了**：指定時刻に保活を停止します。タスク自体を勝手に終了することはありません。
- **静かに動作**：複数の登録で一つの見守りを共有し、余分な会話と出力を抑えます。

### 利用量について

実際の利用では、**5時間の保活でアカウントの利用枠を約2〜3%**消費しました。一つのアカウントでの参考値であり、実際の利用量はプランや実行状況によって異なります。

### 01 · インストール

Grok Bot を開き、次の文章をコピーして送信してください。

```text
このスキルをインストールしてください：https://github.com/aritosi/GrokBot-Cloudstandby
skills/grokbot-cloudstandby フォルダーを、SKILL.md と scripts を含めてすべてインストールしてください。完了したら、まだ起動せずに結果を教えてください。
```

インストール完了の返事が届いたら、使い始められます。

### 02 · 保活を開始

次の文章の時間を必要に応じて変更し、送信してください。

```text
クラウドコンピューターを24時間保活してください。
```

タスクと終了時刻を指定することもできます。

```text
今日の午後11時まで保活してください。
```

起動したいコマンドや実行中のプロセスがある場合は、その情報も一緒に伝えてください。時刻が不明確な場合は、Bot が確認します。

### 03 · 保活を停止

```text
保活を停止してください。
```

## English

GrokBot Cloudstandby is a keep-alive skill for your Grok Bot cloud computer. Keep it active for a chosen period while you connect remotely or run a task.

### What it can do

- **Keep your computer ready** for a few hours or up to 24 hours while you connect remotely or run a long task.
- **Watch a task** by registering an existing process or starting a command you provide, then report when it ends.
- **Stop at your chosen deadline** without terminating your task.
- **Work quietly** by sharing one watcher across registered tasks and keeping repeated output to a minimum.

### Usage

In one real-world test, keeping the computer active for **5 hours used about 2–3% of the account’s allowance**. This is a reference from one account; actual usage varies with the plan, context, and runtime conditions.

### 01 · Install

Open Grok Bot, then copy and send this message:

```text
Please install this skill: https://github.com/aritosi/GrokBot-Cloudstandby
Install the complete skills/grokbot-cloudstandby directory, including SKILL.md and scripts. When installation is complete, tell me the result without starting it yet.
```

Once your Bot confirms the installation, you are ready to begin.

### 02 · Start

Copy this message, change the duration if you like, and send it to your Bot:

```text
Please keep my cloud computer active for 24 hours.
```

You can also name a task and an end time:

```text
Please keep my computer active until 11 PM today.
```

If you want to start a specific command or monitor an existing process, include its details. Your Bot will ask if the time is unclear.

### 03 · Stop

```text
Please stop the keep-alive.
```
